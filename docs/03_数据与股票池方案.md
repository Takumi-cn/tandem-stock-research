## 1. 股票池：中金财富"二级行业第一页"如何落地

### 1.1 勘察结论（全部经过实证）

1. 中金财富**没有公开的、"二级行业第一页"独立 API**；用户**未注册账户**，QMT/xtquant 通道**冻结**（方案存档于工作日志 v1.1 条目，未来开户可启用）。
2. **用户截图确认（2026-10-25）**：免登录状态下"行情报价→二级行业"页签完全可见；页签为 **881xxx 代码体系**（881262 电池、881131 半导体、881218 汽车零部件、881294 通用设备……），名称与**申万 2021 二级行业高度对应**（个别改名如"软件服务"）→ **申万通道 = 基本同口径**。
3. **成分股默认按涨幅%降序**（截图：电池(99) 涨幅榜）→ "第一页"是**派生视图**：系统每日拉取全成分后按选定规则截取前 N 只。
4. 客户端（`D:\中金财富`）为**通达信内核**定制版（T0001/T0002、BlockMap、QHData 等典型结构）→ 本地板块文件可作补充数据源。

### 1.2 通道设计（v1.5 定稿，按优先级）

#### 通道A（并列首选）：akshare 申万二级

```python
import akshare as ak

sw_list = ak.sw_index_second_info()        # 申万二级行业列表（乐咕乐股源）
# 找到"电池"行的指数代码填入 industry_map.csv（检索线索：801730/801731 段位，以接口返回为准）
cons = ak.sw_index_cons(symbol="801730")   # 成分股（该接口受申万源限制可能不稳定）
```

- **接口现状（2026-10-25 核实）**：`sw_index_first_info` / `sw_index_second_info`（乐咕乐股源）稳定；`sw_index_cons` 历史上因申万源问题间歇不可用（GitHub Issue #2421）。
- **降级链**：`sw_index_cons` 失败 → 乐咕乐股源成分接口 → tushare `index_member_all`（校验源，需Token，有2025年停运前科）→ 通道C 手动快照。全部经**接口适配层**（§1.5）管理。
- **映射核验**：P1 建立 `config/industry_map.csv`（`ths_code,sw_name,sw_code,verified`），把客户端 881262 与申万"电池"成分**与客户端界面人工对照一次**，一致后 `verified=yes`。

#### 通道B（补充）：只读解析 `D:\中金财富` 本地板块文件

通达信内核把板块成分存于本地二进制文件（通常在 `T0002\hq_cache\` 的 `block_*.dat` 类文件，格式公开）。仅当通道A持续失效且映射表不完整时启用。纪律：**只读不写**；格式随客户端升级可能变更（纳入适配层）；解析结果与界面人工对照一次。

#### 通道C（保底）：客户端界面手动快照

免登录可见已由截图确认 ✅。用户在 行情报价→二级行业 选中行业，复制右侧第一页清单 → `python -m src.data.import_pool` → `config/stock_pool.csv`。

### 1.3 stock_pool.csv 与"第一页"派生规则（D-23 冻结）


## 2. 行情与基本面数据

### 2.1 字段清单（日线为主频）

| 类别 | 字段 | 来源（主→备） | 历史 |
|---|---|---|---|
| 日线行情 | OHLC、成交量、成交额、换手率、涨跌幅 | akshare `stock_zh_a_hist`(前复权) → baostock+复权因子自算 | ≥5年 |
| 停牌/涨跌停标记 | 由OHLC与规则推导（昨收±限幅、一字板判定） | 自算 | 同上 |
| 行业指数日线 | 申万二级电池指数 + 沪深300（行业相对强弱特征） | akshare 申万指数接口（经适配层） | ≥5年 |
| 资金流 | 主力净流入/大单/中单/小单（日频） | akshare `stock_individual_fund_flow` | ≥3年 |
| 龙虎榜 | 上榜日期、买卖额 | akshare | ≥3年 |
| 财务快照 | 季度营收/净利/PE/PB/ROE | akshare 财务接口（**按公告日对齐**） | ≥5年 |
| 新闻/公告 | 标题+摘要文本 | akshare `stock_news_em` / 公告接口 | 滚动90天 |
| 复权因子 | 前/后复权因子 | baostock（权威）对账 akshare | 同日线 |

### 2.2 存储与质检

- **存储**：`data/` 下 parquet 分区（`year=/dt=/table.parquet`），SQLite 存元信息与快照表。
- **质检脚本（每次拉数自动跑）**：① 日历完整性（对照交易日历找缺日，排除停牌）；② 复权连续性（前复权价在除权日无跳空断裂）；③ 双源对账（akshare vs baostock 收盘价差异 >0.5% 告警）；④ 极值审计（涨跌幅超限价、量为0非停牌等落 `data/quality_issues.csv`）。
- **抓取纪律**：限速（0.5–1s/请求）、失败重试3次退避、断点续传、每日增量+每周全量校验。

## 3. 特征体系设计（P2 落地）

### 3.1 特征族

| 特征族 | 示例 | 数量 | 来源灵感 |
|---|---|---|---|
| 动量类 | 5/10/20/60日收益率、超额（相对电池指数）收益 | ~12 | Alpha158 |
| 波动类 | 已实现波动率（20日）、波动率变化率、ATR | ~6 | Alpha158 |
| 量价类 | 量价相关性、换手率分位数、量能突变（放量/缩量倍数） | ~8 | Alpha158+自研 |
| 技术指标 | KDJ、RSI、MACD、BOLL位置、距20日高点回撤 | ~10 | Alpha158 |
| K线形态 | 连阳/连阴天数、涨停距离、一字板计数 | ~6 | 自研（A股特色） |
| 截面排名类 | 行业内各特征的截面百分位排名 | ~10 | 截面排序标配 |
| 资金流类 | 5日主力净流入占比、大单占比变化 | ~5 | akshare |
| 情绪类 | 新闻情绪均值（3日）、情绪动量、公告计数 | ~5 | FinBERT |
| 财务类 | PE/PB分位数、SUE（盈余惊喜）、营收加速度 | ~6 | 公告日对齐 |

### 3.2 防泄漏工程规范（强制）

- 每个特征函数挂 `@feature_info(available_at="T_close")` 装饰器；单测审计：用 T 日特征预测 T+1 时，任何读取 t>T 数据的实现直接 fail；
- 财务数据按**公告日**（非报告期）进入特征面板；停牌期滚动统计显式填充策略（ffill 最多5日）写入配置。

## 4. 标签设计

| 标签 | 定义 | 用途 |
|---|---|---|
| `ret_1d` | T+1 涨跌幅（前复权） | 回归/排序主标签 |
| `rank_1d` | `ret_1d` 在训练域（电池全成分）内的截面百分位 | **排序主标签** |
| `cls_3` | 涨(>0.5%)/震荡(±0.5%)/跌(<-0.5%) | 三分类副标签（短线轨输出） |
| `ret_5d` | T+5 涨跌幅 | 稳健性检验 |

> 涨跌停样本：T+1 一字板无法买入的样本在**回测**中剔除/按可成交价处理，**训练**中保留。长线轨（000927）的验证方式与短线分离（docs/06 §3.3）。
