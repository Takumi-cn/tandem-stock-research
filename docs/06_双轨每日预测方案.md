# 双轨每日预测方案（标的A短线 · 标的B长线）

> 版本：v1.0 ｜ 日期：2026-10-25 ｜ 状态：规划完成（待用户确认后进 P1）
> 触发：用户收窄交付——**每天（周一至周五）就预测两件事**：① 中金财富二级行业第一页名单中挑一只的**短线**明日走势；② **中国铁物**的**长线**视角明日走势。用户未注册账户（免登录浏览），客户端位于 `D:\中金财富`。

---

## 1. 交付物定义（每天一份报告，两标的）

`reports/YYYY-MM-DD.md`（+HTML 看板），每个交易日 17:30 生成：

| 标的 | 轨道 | 每日输出 |
|---|---|---|
| **A：中金二级行业第一页中挑选的一只**（用户指定 或 系统按次日上涨概率推荐 Top1，概率不足 55% 则不出手） | **短线轨** | 次日上涨概率 + 预期涨跌幅区间 + 置信度 + 多模型投票 + 入场/止损参考位 + 量价/资金/情绪证据摘要 |
| **B：中国铁物（000927）** | **长线轨** | ① 长线仪表盘（趋势阶段/估值分位/距关键均线）+ 操作建议（加仓/持有/减仓/观察）+ 触发提醒；② 明日方向预测（**辅助信号，标注低决策权重**） |

**运行节奏（D-21）**：周一至周五每个交易日 17:30（交易日历自动剔除法定节假日；**周五的"明日"= 下周一**）。非交易日不运行。两标的预测次日收盘后自动复盘，准确率分别独立记账。

**语义澄清（重要）**：长线持有者的"明日走势"不是决策主依据——涨跌 1% 对长线仓位几乎无意义。因此标的B的报告主体是**长线仪表盘与操作建议**，明日方向预测作为辅助参考并明确标注权重。这是诚实的设计，避免把长线决策建立在日频噪声上。

## 2. 短线轨设计（标的A）

### 2.1 标的挑选（`config/targets.yaml`）

> **v3 修订（2026-10-26）**：短线为短期持有服务，auto 模式改为「**次日上涨概率优先**」——对第一页逐只输出上涨概率与预期次日涨幅，取上涨概率最高者；概率低于 **55% 出手线**时明确空仓等待（涨了才赚钱，不为交易而交易）。长线中国铁物按长期持有管理，预测允许涨 / 跌 / 中性，明日方向仅作辅助。

```yaml
# ===== 以下配置已按 D-23 冻结（2026-10-25，用户授权自主决策）=====
short_target: auto      # 系统每日对第一页按次日上涨概率取Top1；概率<55%则空仓等待；如需固定标的改填6位代码
long_target: 000927     # 中国铁物（固定）
industry: 881262        # 短线轨所属二级行业：电池（申万二级"电池"，指数代码以 sw_index_second_info() 返回为准）
pool_view: gainers_desc # "第一页"语义：涨幅降序前N（客户端默认视图）；可改 code_asc 固定
page_size: 20           # 第一页N值，默认20；P1实测客户端每页行数后修正
llm_daily: off          # 本地LLM反思层默认关（D-12/D-14）
```

行业可随时在 `targets.yaml` 一行切换重跑（系统每日本身计算行业相对强弱特征，选择非终身绑定）。

- `auto` 模式：每日对第一页全部股票跑上涨概率模型 → 推荐概率 Top1，**报告必须附全名单概率排名表**（挑选有据可查，不是拍脑袋）；概率不足 55% 时结论为「不出手」；
- 用户指定模式：固定预测该只，报告仍附全名单概率排名供参照。

### 2.2 预测目标与特征侧重

| 项 | 设定 |
|---|---|
| 主标签 | T+1 方向（涨>0.5% / 平±0.5% / 跌<-0.5%） |
| 辅标签 | T+1 涨跌幅点估计与区间；T+3 方向（辅助稳健性） |
| 特征侧重 | 量价异动（放量/缩量倍数、换手率分位）、涨停距离与连板形态、**板块/行业当日强弱与资金净流**、龙虎榜、新闻情绪（FinBERT）、隔夜外盘与指数环境 |
| 模型 | 复用 docs/01 的 L0–L4 引擎与集成层（标签 horizon=1），**训练域用同二级行业全部成分扩池**（防止 20 只小样本过拟合），预测时只输出标的A |

## 3. 长线轨设计（中国铁物 000927）

### 3.1 长线仪表盘（报告主体）

| 模块 | 指标 | 输出 |
|---|---|---|
| 趋势阶段状态机 | 200日/60日均线多空排列、20日新高/新低、唐奇安通道位置 | 上升/震荡/下降 + 转换日期 |
| 估值分位 | PE/PB 近5年分位（行业对照：批发/贸易） | 高估/合理/低估带 |
| 距关键位 | 现价距 200日线、距52周高低点 | 百分比 + 提醒阈值 |
| 基本面日历 | 财报公告日、分红、重大公告（akshare 公告接口） | 未来30日事件提醒 |
| 仓位建议 | 目标波动率法（保守参数，仅示意） | 加仓/持有/减仓/观察 + 一句话理由 |

### 3.2 触发提醒（写报告顶部）

- 收盘跌破 200 日均线 ±1% → "趋势警戒"；估值分位 <15% 或 >85% → 提示；公告财报/重大事项 → 提示。
- 明日方向预测：复用短线引擎（对 000927 单独输出），**标注"对长线决策参考权重低"**。

### 3.3 长线的验证方式（与短线不同）

长线轨不按"明日方向对错"考核主体，而按：仪表盘信号的事后表现（如"趋势警戒"后20日最大回撤）、估值分位与后续收益的秩相关。日报仍记录明日方向对错（辅助信号透明化）。

## 6. 对算力与节奏的影响

- 双标的后**日常数据面极小**（2只标的全量 + 第一页≈20只日线 + 行业指数 + 新闻），日常链路预估压缩到 **3–5 分钟**（关 LLM 层 2–3 分钟），4060 压力进一步降低；
- 模型**训练域仍扩池**（同二级行业全成分），只是预测输出聚焦两标的——小交付、大训练，防过拟合；
- `--deep`/`--night`/一键更新设计不变（docs/04）。
