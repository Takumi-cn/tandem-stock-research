## 1. 调研结论速览

**一句话结论**：不整体引入任何大框架，而是"**取各家之长拼积木**"——微软 Qlib 借特征库与评估协议、清华 Time-Series-Library 取深度时序模型、AAAI'22 HIST 做行业图谱建模、Amazon/Google 时序基础模型做零样本兜底、HKUST FinBERT 做中文情绪、（可选）TradingAgents 做 LLM 多智能体软信号、微软 RD-Agent 作为未来"一键挖因子"的自动升级通道。

### 高校血统透视（应"哈佛/MIT/清华级"要求逐项核实，v1.1 新增）

用户要求选型对标哈佛、MIT、清华级别的顶尖理工高校开源。逐项检索核实后的**真实格局**如下（所有出处均可点击核查）：

| 高校/研究机构 | 代表性开源工作 | 在本项目的角色 |
|---|---|---|
| **清华大学（thuml）** | Time-Series-Library：iTransformer (ICLR'24)、PatchTST (ICLR'23)、TimeXer (NeurIPS'24) 官方实现 | 深度时序模型主供给方 ✅ 已选用 |
| **UC 伯克利** | Informer（AAAI'21 最佳论文，作者团队含 Berkeley 研究者）；Ray/RLlib（RISELab 出品，FinRL 生态底层之一） | 长序列预测奠基工作；分布式算力底座备选 |
| **香港中文大学 CUHK + IDEA 研究院** | DLinear/NLinear（AAAI'23 Oral，arXiv:2205.13504，Ailing Zeng & Qiang Xu） | "反泡沫"批判性基准——L0 基线门槛制度的理论依据 |
| **Mila（魁北克AI研究所）/蒙特利尔大学/麦吉尔** | Lag-Llama（arXiv:2310.08278，末位作者 Irina Rish，已集成 AutoGluon-TS）；N-BEATS 一系血统 | L3 概率预测候选：输出分布而非点值，天然对齐"置信度区间"需求 |
| **哥伦比亚大学** | FinRL 学术起点（现由 AI4Finance 基金会维护） | RL 升级路径观察项 |
| **香港科技大学 HKUST** | FinBERT-tone（含中文金融情感模型） | L4 情绪特征主力 ✅ 已选用 |
| **哈佛 / MIT** | **无此赛道旗舰级开源仓库**（已检索核实） | 如实说明：本细分领域开源主力不在哈佛/MIT，选型不虚标出处 |

**结论**：时序/股票预测开源的全球主力 = 亚洲顶级理工实验室（清华、港中文、港科大）+ 顶尖 AI 研究所（Mila）+ 大厂研究院（微软 Qlib/RD-Agent、Amazon Chronos、Google TimesFM、Salesforce Moirai）。本方案每一层都优先采用**可验证的高校官方实现**；无法满足高校血统的层（时序基础模型层的大厂贡献）如实标注企业研究院出处，拒绝任何虚标。

## 2. 框架层（平台级开源项目）

### 2.1 Microsoft Qlib ⭐ 推荐"借鉴不引入"
- **仓库**：https://github.com/microsoft/qlib （约 33k+ stars）
- **出处**：微软亚洲研究院（论文《Qlib: An AI-oriented Quantitative Investment Platform》，NeurIPS 生态广泛引用）
- **能力**：数据处理→Alpha158/Alpha360 因子库→模型动物园（LightGBM/ALSTM/TRA/**HIST**/ADD/IGMTF）→回测→组合管理，全流程。
- **对本项目价值**：
  - **Alpha158 特征定义**（KDJ/RSI/价格动量窗口/量价相关性等158个算子）——直接移植定义，自行实现约30个核心子集；
  - **滚动前向验证与 IC 评估协议**——照搬其评估纪律；
  - HIST、ADD 等模型的官方高质量实现参考。
- **不整体引入的原因**：Windows 部署链路重（其数据格式bin化、表达式引擎有学习成本），20只股票的小池场景杀鸡用牛刀；引入收益 < 维护成本。**决策 D-03**。

### 2.2 Microsoft RD-Agent ⭐ "一键持续优化"的秘密武器
- **仓库**：https://github.com/microsoft/RD-Agent （Qlib 官方 README 推荐集成）
- **出处**：微软研究院，论文 R&D-Agent-Quant（arXiv:2505.15155）
- **能力**：LLM 驱动的多智能体，全自动完成"读文献→提因子假设→写代码→Qlib回测→迭代优化"的量化研发闭环。论文报告：用 **70% 更少的因子数达到 2 倍年化收益**（相对经典因子库）。
- **对本项目价值**：P6 之后的"深度优化模式"（`一键更新.bat --deep --rd-agent`），让系统每月自动发现新因子。**需要 LLM API Key，设为可选开关**（决策 D-07）。

### 2.3 FinRL（AI4Finance Foundation）⭐ 学术血统最正的 RL 框架
- **仓库**：https://github.com/AI4Finance-Foundation/FinRL （约 10k+ stars）
- **出处**：**起源于哥伦比亚大学**（Columbia University）"Application of Reinforcement Learning to Finance" 校友导师研究项目，现由非营利 AI4Finance 基金会维护；FinRL-Meta 入选 NeurIPS 2022 Datasets & Benchmarks。
- **能力**：DQN/PPO/SAC 等强化学习交易框架，市场环境引擎，实盘接口。
- **对本项目价值**：RL 解决的是"仓位与交易策略"，而本项目核心是"明日方向预测"，目标错位。**列为观察项**：若未来从"预测"扩展到"组合与调仓"，FinRL 是首选升级路径（决策 D-08）。

### 2.4 AI4Finance 生态（FinGPT / FinRobot / FinRL-Meta）
- **FinGPT**：https://github.com/AI4Finance-Foundation/FinGPT （约 16k+ stars，论文 arXiv:2306.06031，千次以上引用）。开源金融 LLM 家族，含**中文金融情感模型**（基于 ChatGLM 微调），在金融情感基准上部分超越 GPT-4。本项目用其情感模型与 FinBERT 互补。
- **FinRobot**：https://github.com/AI4Finance-Foundation/FinRobot —— 金融 AI Agent 开源平台。
- **FinRL-Meta**：实盘数据引擎（NeurIPS 2022）。

### 2.5 TradingAgents（Tauric Research）
- **仓库**：https://github.com/TauricResearch/TradingAgents （2024年末开源即爆火，社区活跃，论文 arXiv:2412.20138 已被引 350+）
- **出处**：Tauric Research（研究机构，非高校）；社区有第三方 GUI（TradingAgents-GUI）。
- **能力**：模拟真实交易公司组织架构的多智能体 LLM 框架：基本面/情绪/技术分析师 → 多空研究员辩论 → 交易员 → 风控团队，输出交易决策与理由。
- **对本项目价值**：P4 可选增强——每日对股票池生成"多空辩论摘要"作为一路软信号并入集成。**注意**：主面向美股数据接口，A股需替换其数据层；按股票×每日调用 LLM 有费用。默认关闭（决策 D-06）。

## 3. 模型层（时序预测 SOTA）

### 3.1 Time-Series-Library（thuml，清华大学）⭐ 深度时序模型统一入口
- **仓库**：https://github.com/thuml/Time-Series-Library
- **收录模型**（均为官方实现、顶会论文）：
  | 模型 | 会议 | 核心思想 | 本项目角色 |
  |---|---|---|---|
  | **iTransformer** | ICLR 2024 | 倒置Transformer：每个变量作为一个token，原生多变量 | 深度时序主力（多股票+多特征矩阵输入） |
  | **PatchTST** | ICLR 2023 | 把序列切成patch当"词"，长上下文 | 单序列建模对照 |
  | **TimeXer** | NeurIPS 2024 | 外生变量增强（行业指数、资金流作为外部驱动） | 行业联动建模利器 |
  | Crossformer / Autoformer 等 | — | 跨变量注意力等 | 备选 |
- **诚实提醒**：DLinear（CUHK+IDEA，cure-lab/LTSF-Linear，AAAI'23 Oral）证明简单线性模型在部分长期预测基准上打平 Transformer——这正是我们坚持 L0/L1 基线门槛制度的原因。

### 3.2 HIST：概念图谱选股（AAAI 2022）⭐ 与本项目场景最契合
- **仓库**：https://github.com/Wentao-Xu/HIST （论文 arXiv:2110.13716）
- **核心思想**：股票共享"预定义概念"（行业、概念板块）与"潜在概念"，用图结构挖掘共享信息预测个股趋势——**本质就是"同行业股票一起看"**，与"中金二级行业成分池"的场景天然匹配。自带 A 股数据与预训练概念图。
- **本项目用法**：以申万/中金二级成分构建预定义概念图，池外同行业股票一并入图增强信号。

### 3.3 时序基础模型（零样本时代）
| 模型 | 仓库 | 出处 | 特点 | 本项目角色 |
|---|---|---|---|---|
| **Chronos-Bolt** | https://github.com/amazon-science/chronos-forecasting | Amazon | 比原版快250×、省内存20×，词元化时序 | 零样本基准+微调候选（CPU友好，优先） |
| **TimesFM** | https://github.com/google-research/timesfm | Google | 解码器-only 基础模型，**TimesFM-3 已支持多变量零预测**（2025发布） | 零样本对照 |
| **Moirai** | https://github.com/SalesforceAIResearch/Uni2ts | Salesforce | 任意频率/多变量统一 | 备选 |
| **Time-MoE** | https://github.com/Maple728/TimeMoE | 开源社区（ICLR 2025） | 10亿参数 MoE 时序模型 | 算力富余时 |
| **Lag-Llama** | https://github.com/time-series-foundation-models/lag-llama | **Mila/蒙特利尔大学+麦吉尔+Amazon**（arXiv:2310.08278） | 轻量（~30MB）概率预测：输出分布而非点值；AutoGluon-TS 集成 | 概率区间预测候选（与置信度输出天然对齐） |
- **用法定位**：对 20 只小池股票，基础模型的"零样本+少样本微调"是数据不足时的重要补充；同时其预测与传统模型相关性低，集成价值高。

## 6. 选型决策记录（ADR 摘要）

| 编号 | 决策 | 理由 |
|---|---|---|
| D-01 | 截面排序为主任务、方向三分类为副任务 | 小池场景下排序目标信息量更大、更可学（Qlib/业界共识） |
| D-02 | LightGBM 为主力模型 | 日频小样本下树模型性价比最高，深度模型做多样性补充 |
| D-03 | Qlib 借鉴不引入 | Windows 部署成本 > 收益；特征定义与评估协议直接移植 |
| D-04 | akshare主+baostock备，不依赖tushare | tushare 停运前科；双源冗余 |
| D-05 | 深度模型统一走 Time-Series-Library 接口 | 官方实现可横向切换 iTransformer/PatchTST/TimeXer |
| D-06 | TradingAgents 默认关闭，作为P4可选 | A股数据层需改造+LLM费用 |
| D-07 | RD-Agent 作为 --deep 模式可选通道 | 免费自动升级因子库，但需LLM Key |
| D-08 | FinRL 列为观察项 | RL与预测目标错位，留作组合管理升级路径 |
| D-09 | 股票池首选通道 = QMT xtquant（枚举板块防错+排序固化），手动快照保底 | 中金口径唯一自动化保真路径 |
| D-10 | 高校血统以可验证真实出处为唯一标准；哈佛/MIT 无此赛道旗舰开源，如实标注 | 拒绝虚标学术出处 |
| D-11 | 增设数据接口适配层（config/api_map.yaml） | akshare 跨版本接口漂移不改业务代码 |
| D-12 | 训练与推理彻底分离；日常 ≤10 分钟、GPU 仅 forward ≤2 分钟；--deep ≤90 分钟 + --night 凌晨自动跑 | RTX 4060 本机每日可用性是硬约束（用户明确） |
| D-13 | Kronos 等 TSFM 降级为特征提取器+合成数据增强，不作直接零样本预测器 | 2026 年约 5000 股实证：Kronos 未跑赢简单波动率基准（BSQ 重尾失真） |
| D-14 | LLM 预测器只做推理时反思（SEP 式、top-5 限定、默认关），不做 GRPO/Time-GRPO 训练 | 4060 无法承担 7B 级 RL 训练 |
| D-15 | 前沿引入顺序：官方开源 > 近亲开源+论文机制自实现（FactorMoE 式路由→TGNS 式双重注意力→非平稳补偿；Mamba 系降 WSL2 可选） | NSC-Mamba/TGNS 已核实无官方代码；自实现件须过 L0/L1 门槛 |
| D-16 | 漂移适应轻量化：DDD（PSI/ADWIN 检测）+ 集成权重在线重校准，不做完整 RL-DAM | 满足日常 10 分钟预算 |
| D-17 | 排序训练引入 WRL 式指数加权损失，对齐多空组合收益 | 损失层对齐下游目标（TGNS 证据） |

## 8. 前沿方向增补（v1.2：用户提供调研 + 代码可得性核实）

> 2025–2026 前沿的共同逻辑：把非平稳性、状态切换、关系漂移当作一等公民显式建模；评测转向 IC+风险调整收益+解释质量+漂移鲁棒性。完整落地与 4060 算力适配见 **docs/05**。

| 状态路由 | FactorMoE（市场状态门控 Chained-MoE；券商实证 RankIC 4.60%→6.10%） | 未核实（P3 复核） | 轻量版先行：状态指标+因子近期表现→门控 | docs/05 §2.3 |
